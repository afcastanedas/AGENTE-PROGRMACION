# media/

Pon aquí tus imágenes y videos reales de proyectos.

Luego, en `data.js`, referencia cada archivo con su ruta relativa a esta carpeta, por ejemplo:

```js
{ id: 1, title: 'Mi proyecto', category: 'Editing', type: 'video', src: 'media/mi-proyecto.mp4', poster: '' }
```

Este archivo (`README.md`) es solo un marcador para que la carpeta exista en el repositorio —
bórralo cuando ya tengas tus propios archivos aquí.
